# 需求覆盖与阶段边界

第一阶段是可用文本闭环，第二阶段协作扩展，第三阶段治理。[需求](product-requirements.md)保留整体产品目标，具体交付顺序以本文和[清单](../todo.md)为准。

| 需求/案例 | 责任模块与入口 | 阶段/任务 | 验收重点 |
| --- | --- | --- | --- |
| A01 创建与执行 | task/execution 应用用例 | 一 M04/M05/M06 | 真实 Buddy 认领、文本交付 |
| A02 意图不明确 | commands/question 请求输入（已实现本地闭环，见 [M05](m05-workflow.md#请求输入与人工引导)） | 一 M05/M06 | 问答不授予任意操作权限；未答问题阻止完成 |
| A03/A09 差异权限 | access + 命名用例 | 一 M03/M06；扩展二 M09 | 未授权规划/改目标明确拒绝 |
| A04 规划与成组变更 | plan | 二 M08/M09 | 授权范围、原子变更、无环 |
| A05 多 Buddy/父任务 | plan/results | 二 M08 | 单任务单执行，父有独立结果 |
| A06 并发修改 | task/command | 一 M03/M04 | 不静默覆盖 |
| A07 依据历史与影响 | task/results/plan | 一 M04/M05；树二 M08 | 展示旧结果依据，变更不自动通过 |
| A08 历史树恢复 | plan/history 用例 | 三 M10 | 新变更、不恢复旧授权/运行/副作用 |
| A10 验收分离 | results/access | 一 M05 | 代理身份不可绕过 |
| A11 掉线/替换 | execution | 一 M05/M06 | 未知不重派、过期写拒绝 |
| A12 事件与重连 | 授权 feed/HTTP | 一 M04/M06 | 无漏窗、去重、超期重同步 |
| A13 取消 | lifecycle/execution | 一 M05/M06 | 取消不冒充停止 |
| A14/A15 撤销与隔离 | access/全部查询 | 一 M03/M06；附件二 M07 | 当前、历史、事件均隔离 |
| A16 平台升级接入 | 身份适配/Agent 联调 | 一 M02/M06 | 新实例不得冒用旧执行 |
| C01—C11/C13/C15—C18 | 命令模块/流程控制 | 一 M03—M06 | 事务、轮次、证据与安全 |
| C12 文件/链接、C14 确认子任务 | artifacts/plan/access | 二 M07—M09 | 引用保留和一次确认 |
| 搜索/提醒/项目组织 | 查询/inbox/task | 二 M09 | 授权分页、无自消费循环 |
| 完整树快照/恢复/复杂治理 | history/access | 三 M10 | 恢复范围、性能与审计 |

第一阶段单企业部署验证但所有数据有租户隔离；独立任务、单有效执行、最小动作/范围授权、文本结果、必要修订历史、阻塞问答和薄界面。未实现拆解、附件、复杂授权或确认动作明确拒绝，不用恒成功替身宣称正式能力。

第二阶段单父树，同项目或独立树内依赖；跨项目/跨树默认关闭。父取消不隐式取消子任务，取消子任务不满足依赖；终态父调整正式计划先重开。父完成须独立结果及完成检查。项目可选，先做组织、成员与范围。权限移动检查源/目标及历史材料，不借引用扩权。超时仅提醒，不推定同意/取消/重派。

第三阶段恢复只覆盖选定目标/标准/计划，形成新变更；不恢复运行状态、旧权限、停止证据或外部副作用。复杂分支流程、跨企业协作、多级会签、多父图、自动重派、分支合并仍为候选，未授权前不做默认能力。

## 模块组合扩展验收

E01—E03 已在 M05 本地验证（见 [M05](m05-workflow.md#验证范围)），E04 待 M09：

| 案例 | 交付位置 | 验收条件 |
| --- | --- | --- |
| E01 本地事实审核步骤 | M05 | 新增 State 与配置，原交付命令不改；业务未过保留交付并等待，技术失败回滚 |
| E02 人工/异步审核步骤 | M05 | 新状态按需自有记录和输入 API，原控制器不改；旧候选结论不可复用 |
| E03 新 API 模块 | M05 | 新增模块与配置，HTTP 不改；路由冲突/认证/退出可验证 |
| E04 新通知渠道 | M09 | 新增渠道与配置，原业务和通知消费者不改；逐渠道重试 |

现有 C01—C18 约束仍必须同时通过，不能以可扩展为理由允许配置绕过权限、执行代次、证据或事务保护。
